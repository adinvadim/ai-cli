---
title: Configuration
description: Environment variables and defaults.
---

ai-cli uses environment variables for defaults and flags for each request. Image
and video commands also accept JSON files for SDK provider options, headers,
and structured media inputs. There is no global config file.

## Environment variables

<Properties>
  <Property name="AI_GATEWAY_API_KEY" type="string">
    Vercel AI Gateway API key. Takes priority over the key saved by `ai login`.
  </Property>
  <Property name="AI_GATEWAY_BASE_URL" type="string">
    Gateway baseURL for decide, image/video generation, and model discovery. Override with `--base-url`.
  </Property>
  <Property name="AI_GATEWAY_TEAM_ID_OR_SLUG" type="string">
    Gateway teamIdOrSlug for decide, image/video, and models. Override with `--scope`.
  </Property>
  <Property name="AI_CLI_PROVIDER" type="gateway | openrouter | codex | grok">
    Default provider for text, image, video, and models. Override with `--provider`. See [Providers](/docs/providers).
  </Property>
  <Property name="OPENROUTER_API_KEY" type="string">
    OpenRouter API key for `--provider openrouter`.
  </Property>
  <Property name="XAI_API_KEY" type="string">
    xAI API key for `--provider grok` when there is no `grok login` session.
  </Property>
  <Property name="CODEX_HOME" type="path">
    Codex CLI home containing `auth.json`. Defaults to `~/.codex`.
  </Property>
  <Property name="GROK_HOME" type="path">
    Grok CLI home containing `auth.json` and `bin/grok`. Defaults to `~/.grok`.
  </Property>
  <Property name="AI_CLI_TEXT_MODEL" type="string">
    Default text model. Overrides `openai/gpt-5.5`.
  </Property>
  <Property name="AI_CLI_IMAGE_MODEL" type="string">
    Default image model. Overrides `openai/gpt-image-2`.
  </Property>
  <Property name="AI_CLI_VIDEO_MODEL" type="string">
    Default video model. Overrides `bytedance/seedance-2.0`.
  </Property>
  <Property name="AI_CLI_SPEECH_MODEL" type="string">
    Default speech model. Overrides `openai/tts-1`.
  </Property>
  <Property name="AI_CLI_TRANSCRIPTION_MODEL" type="string">
    Default transcription model. Overrides `openai/whisper-1`.
  </Property>
  <Property name="AI_CLI_EVALUATION_MODEL" type="string">
    Default evaluation model for `decide`. Overrides `typesafe-ai/jev`.
  </Property>
  <Property name="AI_CLI_OUTPUT_DIR" type="path">
    Default output directory for generated files.
  </Property>
  <Property name="AI_CLI_PREVIEW" type="0 | 1">
    `1` forces inline preview on, `0` disables it.
  </Property>
  <Property name="NO_COLOR" type="any">
    Disable ANSI color output.
  </Property>
  <Property name="FORCE_COLOR" type="any">
    Force color output even when not a TTY.
  </Property>
</Properties>

## Precedence

- `-m` flag always takes priority over `AI_CLI_*_MODEL` env vars.
- `--provider` takes priority over `AI_CLI_PROVIDER`. `AI_CLI_*_MODEL` apply to the default provider only.
- `-o` flag always takes priority over `AI_CLI_OUTPUT_DIR`.
- `--no-preview` takes priority over `AI_CLI_PREVIEW`.

## Example shell profile

```bash
export AI_GATEWAY_API_KEY="gw_..."
export AI_CLI_TEXT_MODEL="anthropic/claude-sonnet-4"
export AI_CLI_IMAGE_MODEL="bfl/flux-2-pro"
export AI_CLI_SPEECH_MODEL="openai/tts-1"
export AI_CLI_OUTPUT_DIR="$HOME/ai-output"
```
