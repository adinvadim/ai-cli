## Default models

Defaults depend on the selected provider (`gateway` or `openrouter`):

| Type | Gateway | OpenRouter | Env override |
| --- | --- | --- | --- |
| text | `openai/gpt-5.5` | `openai/gpt-5-mini` | `AI_CLI_TEXT_MODEL` |
| image | `openai/gpt-image-2` | `openai/gpt-5-image-mini` | `AI_CLI_IMAGE_MODEL` |
| video | `bytedance/seedance-2.0` | `bytedance/seedance-2.0` | `AI_CLI_VIDEO_MODEL` |

The `-m` flag always takes priority over environment variables.

## Specifying a model

Use `creator/model-name` format:

```bash
ai text -m "anthropic/claude-sonnet-4" "hello"
ai image -m "bfl/flux-2-pro" "a sunset"
```

Short names (without the creator prefix) are resolved against models fetched from the selected provider:

```bash
ai text -m gpt-5.5 "hello"
ai image -m flux-2-pro "a sunset"
```

## Multi-model comparison

Generate with multiple models by comma-separating `-m`:

```bash
ai image "a sunset" -m "openai/gpt-image-1,xai/grok-imagine-image,bfl/flux-2-pro"
```

Combine with `-n` to generate multiple per model:

```bash
ai image "a sunset" -n 2 -m "openai/gpt-image-1,bfl/flux-2-pro"
```

This produces 4 images total (2 per model), saved as `output-1.png` through `output-4.png`.

## Listing models

```bash
ai models                          # all models
ai models --type image             # image models only
ai models --creator google         # Google models only
ai models --provider openrouter    # OpenRouter models
ai models --json                   # JSON with descriptions
```

In human mode, models are grouped by creator and display short names. Use `--json` for machine-readable output with full IDs and descriptions.

## Provider selection

Order:

1. `--provider gateway|openrouter`
2. `AI_CLI_PROVIDER`
3. Auto-infer: only `OPENROUTER_API_KEY` (no `AI_GATEWAY_API_KEY`) → `openrouter`, else `gateway`

```bash
ai text --provider openrouter -m "anthropic/claude-sonnet-4" "hello"
export AI_CLI_PROVIDER="openrouter"
```

OpenRouter requests use `OPENROUTER_API_KEY`. Model discovery reads live data from the selected provider.
